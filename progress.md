# Rini Pandit Demo - Progress & Feature Checklist

## Proposed Core Demo Features (High-Priority for AstroTalk Benchmark)

- [ ] **1. User Authentication & Profile**
  - Phone / OTP or quick login
  - User birth details setup (Name, DOB, Time, Place of Birth)
- [ ] **2. Astrologer Marketplace & Profiles**
  - Categorized listing (Vedic, Tarot, Numerology, Vastu)
  - Profile view (rate/min, experience, rating, availability status)
- [ ] **3. Live Consultation System (Chat & Session)**
  - Initiate chat consultation with astrologer
  - Real-time messaging connected to backend
  - Per-minute active session timer & status
- [ ] **4. Wallet & Per-Minute Billing Engine**
  - Wallet balance display & quick recharge (mock/Razorpay test)
  - Balance deduction based on consultation duration
- [ ] **5. Free Astrology Utilities**
  - Daily Horoscope display
  - Basic Kundli Generator calculation output
- [ ] **6. Astrologer / Admin Quick Dashboard (Backend)**
  - View incoming consultation requests & session status
